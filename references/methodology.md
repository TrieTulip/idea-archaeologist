# ARCHAEOLOGY 方法论

本文件只在标准问题突破、深度探索或阶段转换不清时加载。字母 `A` 同时对应 Analyze 与 Associate；正文用 `As` 标记 Associate，避免混淆。

## 阶段路径

| 任务 | 标准路径 | 快速路径 |
|---|---|---|
| 灵感挖掘 | A → R → C → E → O | A → R → 精简 C → E → O |
| 跨界探索 | A → R → C → H → As → E → O | A → R → C → H → E → O |
| 问题突破 | A → R → C → H → As → E → O → L | A → R → E → O |
| 知识考古 | A → R → H → As → E → O → L | A → R → E → O |
| 创意评审 | A → R → O → L | A → R → O → L |
| 灵感复盘 | R → O → L → Op | R → O |

深度模式使用九阶段全流程 `A → R → C → H → As → E → O → L → Op`。省略阶段必须由任务复杂度决定，不能为了省 Token 隐藏关键判断。

## A — Analyze

把表面请求转换为工作问题：

- 谁在什么场景希望改变什么结果？
- 已有做法为什么不够？
- 哪些约束不可违反？
- 成功与失败各如何观察？

输出一句包含对象、目标、约束和未知项的问题陈述。若方向完全取决于一个缺失条件，追问；否则写成显式假设继续。

**转入 R**：问题已足够明确，且关键成功标准已知或已假设。

## R — Retrieve

只提取可能改变后续方向的信息：

- 核心概念及其本任务定义。
- 用户陈述、可核验事实、一般知识、推断和假设。
- 隐含假设、机会、约束和未解决问题。
- 历史知识索引中的相关主题与去重键。

**转入 C/H**：概念边界清楚；事实缺口不会使所有后续方案失去意义。

## C — Cross-domain

选择相关领域时覆盖同领域、相邻领域、远距离或反常识视角中的必要部分，不为数量凑学科。

每个领域至少产出一个：

- 可描述机制。
- 反例。
- 新的约束。

没有检索能力时标注“一般知识 / 待核实 / 仅作启发”。

**转入 H**：已经找到至少一个可以说明机制的候选连接。

## H — Hypothesize

把连接写成可审查假设：

```text
概念 A：
概念 B：
共同机制或结构：
关联类型：
迁移条件：
失效条件或反例：
置信度：
```

采用“如果前提 X 成立，机制 Y 可能改善结果 Z”的格式。说不出失效条件时缩小假设，而不是扩大承诺。

**转入 As**：机制的迁移边界已经明确。

## As — Associate

从组合创新、类比迁移、逆向思考、极端假设、结构重组中选择真正会改变变量的方法。至少一个候选挑战默认假设，至少一个候选主动改善可执行性。

**转入 E**：组合方向在机制、交互、场景、资源或风险上存在实际差异。

## E — Explore

按“问题 → 关联 → 初步候选 → 差异检查 → 质量筛选 → 深度评估”生成。数量由任务决定：

- QUICK：约 1–3 个有用方向。
- STANDARD：通常 3–5 个差异方向。
- DEEP：足以覆盖主要机制空间，不设机械数量下限。

每个保留候选说明名称、核心构想、灵感来源、推导、目标问题、场景和潜在价值。

**转入 O**：候选之间已经完成首轮去重。

## O — Observe

用 Critic 视角检查：

- 已有直接或近邻替代方案？
- 新颖性来自机制、组合或场景，还是只来自命名？
- 关联依赖哪些未说明或不可实现的前提？
- 价值是否建立在单一未验证假设上？
- 是否有更小、更便宜的版本？
- 谁最可能反对，最强反例是什么？
- 是否存在隐私、伦理、安全、权利或维护风险？

严重缺陷优先缩窄或重定义，不用高分掩盖。

**转入 L**：保留推荐项，或其失败原因需要实验区分。

## L — Launch

为优先候选设计最小实验：

- 唯一核心假设。
- 对象、范围和资源上限。
- 可逆步骤。
- 成功信号、失败信号和停止条件。
- 可能的副作用或测量偏差。

优先顺序：已有数据 → 一次访谈/观察 → 纸面原型 → 小样本交互 → 更完整原型。

## Op — Optimize

只在存在真实探索记录和反馈时执行：

1. 已确认观察：有原话、文件或结果支持。
2. 待确认推断：样本不足，不能升级为稳定偏好。
3. 建议更新：具体流程、模板或记录字段。
4. 需要授权：核心方法、评分权重或正式偏好。

累计 10 次有效探索后再建议阶段趋势；历史不足时明确样本数。

## 阶段跳跃与停止

- 已有候选且只要求判断：从 A/R 直接进入 O，再按需 L。
- 只需整理旧资料：从 R 开始；概念定义不清时进入 H。
- 历史数据不足的复盘：在 R/O 停止，不进入趋势推断。
- 风险信息缺失且会误导：保留条件式假设，先提出必要证据。
- 用户只要求简单点子：完成 A/R/E/O 即可，不加载完整方法。
