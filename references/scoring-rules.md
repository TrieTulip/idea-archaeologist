# 关联审查、评分与验证

只在需要比较候选、检查关联、筛选推荐项或设计验证时加载。

## 关联质量门禁

任何关键关联都要检查：

1. 定义一致性。
2. 共同机制。
3. 迁移条件。
4. 失效条件。
5. 替代解释。
6. 核实状态。

至少缺少机制或迁移条件的关联降为“弱启发”。`R < 6` 或主要由表面类比支撑时，不进入无条件推荐。

## 评分公式

`Score = 0.25N + 0.20R + 0.25V + 0.20F + 0.10E`

| 维度 | 判断问题 |
|---|---|
| N 新颖性 | 与已知/常见方案相比，差异是否明显且有意义？ |
| R 关联合理性 | 机制、条件和边界是否有依据？ |
| V 实用价值 | 是否解决重要问题，价值能否被观察？ |
| F 可行性 | 资源、技能、时间、合规与协调是否具备？ |
| E 延展性 | 能否扩展到新场景或产生后续学习？ |

每项 1–10 分：

| 分数 | 锚点 |
|---|---|
| 1–2 | 几乎不成立或无可观察价值 |
| 3–4 | 严重缺口，只是早期线索 |
| 5–6 | 部分可信，需要关键条件或优化 |
| 7–8 | 有较强依据，仍需现实验证 |
| 9–10 | 多方面成立，但仍不是实验证明 |

只对进入比较或推荐的候选完整评分；短请求不强制评分。

## 评分记录

每个评分组至少包含：

- N/R/V/F/E 五项分数与短理由。
- 加权结果。
- 评分置信度：高 / 中 / 低。
- 最影响结论的不确定性。
- 是否触发关联警告。
- 最强反例。
- 与分数似乎不一致的直觉或风险。

评分是排序辅助，不是精确概率、客观测量或用户认可率。

## 硬性降级

以下任一情况不能因总分高而直接推荐：

- 新颖性只靠改名字。
- R < 6。
- 核心价值依赖未经验证且无法验证的高风险假设。
- 已有方案以明显更低成本解决同一问题。
- 缺少最低实施条件且没有替代路径。

## 最小验证

推荐项只需验证最危险的一个核心假设：

```text
核心假设：
支持信号：
失败或停止信号：
最小观察：
资源上限：
可逆性：
```

一次只改变一个关键变量。更便宜的已有数据、访谈或纸面原型优先于完整产品。
