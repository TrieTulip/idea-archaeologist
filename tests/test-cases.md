# Phase 2 能力测试用例

这五组测试验证 Skill 的可观察行为。每个用例都从用户请求开始，以模式识别、流程范围、关联质量和评价结果作为检查对象。

## 测试环境

- 测试日期：2026-11-01
- Skill 版本：Phase 1 基础构建
- 本地知识库：无历史记录文件
- 外部检索：不可用
- 事实策略：明确标注一般知识、推断或创意假设，不生成虚构来源
- 评价性质：同一执行环境中的自检，不等同于独立用户或外部评审

## 通用通过条件

1. 选中的工作模式与用户想要的结果一致。
2. 只执行该模式需要的阶段，不机械套用九章节报告。
3. 跨领域选择有理由，关联说明机制、条件和失效边界。
4. 弱关联触发警告，不因叙事完整而进入高价值推荐。
5. 每项评分附带理由、置信度和主要不确定性。
6. 加权分符合 `0.25N + 0.20R + 0.25V + 0.20F + 0.10E`。
7. 没有虚构论文、统计、用户偏好或历史记录。
8. 没有未经用户授权写入知识库。

## TEST 01：普通灵感挖掘

- **输入**：如何提高长期学习动力？
- **预期模式**：1. 灵感挖掘
- **预期路径**：A → R → C（精简）→ E → O
- **深度**：标准
- **核心检查**：能否从不同领域找到有实际用途的关联，同时识别表面类比？
- **最低候选数**：5
- **必须出现**：至少一个关联警告、一个低成本验证动作
- **禁止行为**：把所有候选都评为高价值；用“复利”等比喻替代因果机制

## TEST 02：跨界探索

- **输入**：把咖啡馆和知识管理联系起来。
- **预期模式**：2. 跨界探索
- **预期路径**：A → R → C → H → A → E → O
- **深度**：标准
- **核心检查**：能否产生机制不同且具有应用价值的创新构想？
- **最低候选数**：5
- **必须出现**：第三空间、服务流程、空间线索或类似机制的解释
- **禁止行为**：只做“咖啡馆 + 笔记软件”的换皮；忽略隐私、维护或社交负担

## TEST 03：知识考古

- **输入**：分析第一性原理及其在产品设计中的应用。
- **预期模式**：4. 知识考古
- **预期路径**：A → R → H → A → O
- **深度**：标准
- **核心检查**：能否从原理迁移到具体实践，并说明何时不适用？
- **最低应用候选数**：5
- **必须出现**：第一性原理的工作定义、错误使用边界、一个可执行实验
- **禁止行为**：把第一性原理包装成“忽略用户研究”；声称存在未经核实的论文或历史出处

## TEST 04：创意评审

- **输入**：开发一个自动整理阅读资料并生成知识图谱的应用。
- **预期模式**：5. 创意评审
- **预期路径**：A → R → O → L
- **深度**：标准
- **核心检查**：能否识别优势、风险、竞争差异和实施条件？
- **必须出现**：当前方案评分、主要替代方案、收窄或差异化版本、验证实验
- **禁止行为**：仅因“有知识图谱”就判断新颖；虚构市场规模或竞品功能

## TEST 05：长期进化

- **输入**：整理历史探索，生成知识更新和优化建议。
- **预期模式**：6. 灵感复盘
- **预期路径**：R → O → L → O
- **深度**：受历史数据约束
- **核心检查**：能否正确识别历史记录、避免虚构记忆并输出更新内容？
- **预期事实**：当前知识库为空，历史数据不足
- **必须出现**：零记录说明、不可计算的统计口径、不写入知识库的声明
- **禁止行为**：虚构十次探索、虚构认可率、虚构用户偏好或声称已生成正式阶段趋势
